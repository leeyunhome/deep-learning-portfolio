01. PyTorch 선형회귀 & Autograd

scikit-learn에 내장된 당뇨병 환자 442명의 실제 임상 데이터에서 BMI(체질량지수) 하나로 1년 뒤 질병 진행도를 예측하는 선형 모델을 nn.Module과 경사하강법으로 직접 학습시켰습니다. loss.backward()가 만드는 계산 그래프를 torchviz로 시각화했고, 강의에는 없던 SGD vs Adam 수렴 속도 비교 실험을 추가했습니다.

PyTorch nn.Module Autograd SGD / Adam real dataset (n=442)

데이터: 강의 예제 대신 실제 임상 데이터

강의는 이해를 돕기 위해 임의로 만든 5개의 숫자 쌍을 사용하지만, 여기서는 scikit-learn이 제공하는 442명의 당뇨병 환자 임상 기록 (Efron et al., 2004)에서 BMI 한 컬럼만 입력으로 골라 사용했습니다. 노이즈가 많고 완벽한 직선으로 설명되지 않는, 있는 그대로의 실제 데이터입니다. 

from sklearn.datasets import load_diabetes

diabetes = load_diabetes()
bmi_index = diabetes.feature_names.index("bmi")

bmi = diabetes.data[:, bmi_index].astype(np.float32)          # 입력: BMI (표준화됨)
progression = diabetes.target.astype(np.float32)              # 목표: 1년 뒤 질병 진행도

모델과 학습 루프

nn.Linear(1, 1)이 w, b를 nn.Parameter로 들고 있고 requires_grad=True 상태이므로, backward() 한 번으로 두 파라미터의 기울기가 채워집니다. 

class BmiToProgression(nn.Module):
    def __init__(self, w0=0.0, b0=0.0):
        super().__init__()
        self.line = nn.Linear(in_features=1, out_features=1)
        with torch.no_grad():
            self.line.weight.fill_(w0)
            self.line.bias.fill_(b0)

    def forward(self, x):
        return self.line(x)


def train(model, optimizer, epochs=2000):
    criterion = nn.MSELoss()
    history = []
    for epoch in range(epochs):
        for xb, yb in loader:
            pred = model(xb)
            loss = criterion(pred, yb)

            optimizer.zero_grad()      # 기울기는 누적되므로 매 스텝 초기화
            loss.backward()
            optimizer.step()

            history.append(loss.item())

        if epoch == 0:
            # 첫 스텝의 계산 그래프를 저장해 backward가 어떤 경로로
            # 기울기를 전파하는지 확인한다.
            graph = torchviz.make_dot(loss, params=dict(model.named_parameters()))
            graph.save("../docs/assets/autograd_graph.gv")

    return history

SGD vs Adam 비교 — 강의에 없던, 직접 추가한 실험

model_sgd = BmiToProgression()
history_sgd = train(model_sgd, optim.SGD(model_sgd.parameters(), lr=0.8))

model_adam = BmiToProgression()
history_adam = train(model_adam, optim.Adam(model_adam.parameters(), lr=2.0))

충분한 epoch로 학습하니 SGD와 Adam 모두 numpy.polyfit으로 구한 최소제곱법 정확해와 거의 일치했습니다 — 경사하강법이 실제로 수학적 최적해에 수렴한다는 것을 실제 데이터로 확인한 부분입니다.

배운 점

  • loss.backward()는 순전파에서 만들어진 계산 그래프를 거꾸로 타고 올라가며 w, b 각각에 대한 기울기를 누적한다 — torchviz로 그 경로를 직접 확인했다.
  • 기울기가 누적되기 때문에 매 스텝 zero_grad()가 필요하다.
  • 학습률이 너무 크면 발산·진동한다는 것을 직접 재현했다. 처음 SGD 학습률을 1.0으로 뒀더니 w는 정확해에 수렴했지만 b는 0 근처에서 계속 진동했다. full-batch MSE에서 b에 대한 손실은 2차함수이고 lr < 2 / 곡률 조건을 넘어서면서 매 스텝 부호가 뒤집히는 진동이 생긴 것이었다 — 학습률을 0.8로 낮추자 두 파라미터 모두 수렴했다.
  • 충분히 학습된 경사하강법은 이 문제에서 최소제곱법과 같은 해로 수렴한다.
Dataset 클래스 (재현용) 
class PatientsDataset(Dataset):
    """BMI(입력)와 질병 진행도(목표값) 쌍을 담는 Dataset."""

    def __init__(self, features, targets):
        self.features = torch.from_numpy(features).unsqueeze(1)
        self.targets = torch.from_numpy(targets).unsqueeze(1)

    def __len__(self):
        return self.features.shape[0]

    def __getitem__(self, idx):
        return self.features[idx], self.targets[idx]


dataset = PatientsDataset(bmi, progression)
loader = DataLoader(dataset, batch_size=len(dataset), shuffle=False)
